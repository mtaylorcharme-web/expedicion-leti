# Expedición Leti

App web de estudio para 5º básico (Colegio Bradford · currículo MINEDUC), con los personajes Ovaya, Chupaya y Estaya.

- **Sin dependencias ni instalación**: HTML, CSS y JavaScript puros. Se abre en cualquier navegador (tablet o computador) y se puede instalar en la pantalla de inicio.
- **Contenido**: `js/content-historia-u3.js` — Historia, Unidad 3 «La expansión europea» (prueba del 24 de septiembre).
- **Progreso**: se guarda en el dispositivo (localStorage). El panel para mamá tiene PIN (inicial: 1234).

## Ejecutar en local
Abre `index.html` en el navegador, o sirve la carpeta con cualquier servidor estático.

## Publicar
La carpeta completa se publica tal cual en GitHub Pages (rama `main`, carpeta raíz).
